# About This Project

I wanted to create the most beautiful website in the world. I also wanted to improve my skills in CSS and JavaScript and learn more about web development.

I created this website for my Lichess team, Galaxy Stellar Chess, to give our community its own place on the internet. My goal was to combine my passion for chess with my creativity and build a unique website with a space-inspired design.

This project is an opportunity to learn, experiment and improve my coding skills while creating something special for my team.
